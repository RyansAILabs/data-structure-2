* com flag de parada antecipada. Todos são in-place (O(1) de memória extra). Selection faz sempre n(n−1)/2 comparações — para n = 5, 10; n = 8, 28; n = 10, 45.

Bubble

Assinatura no código: swap(i, i+1) e flag changed. Se a passada não troca, para.

Insertion

Assinatura: key + laço while (j >= 0 && v[j] > key) deslocando. Melhor para quase ordenado.

Selection

Assinatura clássica: minIndex + uma troca por posição. O sort() do repositório troca a cada valor menor. Instável: [3a, 3b, 1] → [1, 3b, 3a].

O descritor guarda size, inicio e fim. Ele não dá acesso direto ao meio: get continua O(n).

03 Listas: o essencial

Sequencial

  • elements + count; posições 0..count−1.
  • add no fim O(1); inserir/remover no início O(n) por deslocamento.
  • insert aceita posição 0..count; get/remove, 0..count−1.
  • Inserir: laço para trás (i = count; i > pos; i--).
  • Remover: laço para frente (i = pos; i < count−1; i++).
  • pop() = remove(0) (convenção da lista encadeada; o repo deixa em branco).

Encadeada

  • Nó = valor + next (+ prev na dupla).
  • Sem acesso por índice: get(i) percorre O(n).
  • Sem descritor, inserir no fim e size() são O(n).
  • Com descritor, extremidades e tamanho são O(1).
  • Na dupla, remover nó conhecido é O(1) (tem prev).
  • Nós não são contíguos; a ordem vem dos ponteiros.
  • A classe do repo tem capacity e isFull(): ela enche.

Receitas de ponteiros (decore a ordem)

SIMPLES — inserir depois de p:
    novo.next = p.next;      // 1) salva o resto
    p.next = novo;           // 2) religa p

SIMPLES — remover o primeiro:
    inicio = inicio.next;
    if (inicio == null) fim = null;
    size--;

SIMPLES — remover o nó alvo (precisa do anterior):
    anterior.next = alvo.next;
    if (alvo == fim) fim = anterior;
    size--;

DUPLA — inserir novo entre anterior e próximo:
    novo.prev = anterior;
    novo.next = próximo;
    anterior.next = novo;
    próximo.prev = novo;

DUPLA — remover x:
    if (x.prev != null) x.prev.next = x.next; else inicio = x.next;
    if (x.next != null) x.next.prev = x.prev; else fim = x.prev;
    size--;

04 Pilhas e filas

EstruturaPolíticaInsereRemoveConsultaCusto
PilhaLIFOpush no topopop do topopeek topoO(1)
FilaFIFOenqueue no fimdequeue da frentepeek frenteO(1)

Pilha com vetor

top = -1 (vazia)
push: data[++top] = v;
pop:  v = data[top--];
peek: data[top];

Fila circular

enqueue: data[rear] = v;
         rear = (rear + 1) % cap;
         count++;
dequeue: v = data[front];
         front = (front + 1) % cap;
         count--;
vazia: count == 0
cheia: count == cap
⚠️
Sem campo count

Muitas implementações reservam uma posição vazia: cheia quando (rear + 1) % cap == front; vazia quando front == rear. Nesse caso cabem cap − 1 elementos. Se o enunciado tiver count, use count == cap / count == 0.

05 Pós-fixa e parênteses

Avaliar pós-fixa

  1. Número → push.
  2. Operador → pop direita, depois pop esquerda.
  3. Calcule esquerda op direita e empilhe.
  4. No fim, o resultado é o único valor da pilha.

Exemplo: 6 2 3 * - 4 + → (6 − 6) + 4 = 4.

Infixa → pós-fixa

  1. Operando → saída.
  2. Operador → desempilha enquanto o topo tiver precedência ≥; empilha o novo.
  3. ( empilha; ) desempilha até o (.
  4. Fim → desempilha tudo.

Exemplo: A + B * C − D → A B C * + D −.

Parênteses balanceados: abertura empilha; fechamento desempilha e confere o par; no fim, pilha vazia. Se fechar sem abrir, ou o par não casar, é falso.

06 As 16 pegadinhas que mais custam ponto

  1. Contar passada do Bubble: uma passada completa percorre todos os pares do trecho atual. Não pare no meio.
  2. Selection é instável. Não diga que “todos os O(n²) são estáveis”.
  3. Selection não tem melhor caso: faz n(n−1)/2 comparações sempre. Na versão clássica são ≤ n−1 trocas; o sort() do repositório troca a cada valor menor.
  4. Insertion não é “bolha”: ele desloca e encaixa uma chave; o prefixo é ordenado, não o sufixo.
  5. Insertion estável só com comparação estrita (>), não >=.
  6. Faixa de inserção: 0..count; leitura/remoção: 0..count−1.
  7. Deslocamento do insert: de trás para frente. Do remove: de frente para trás.
  8. Ordem dos ponteiros: salve p.next antes de sobrescrever, senão perde a lista.
  9. Descritor não dá acesso O(1) ao meio: get continua O(n).
  10. Pós-fixa: segundo pop é o operando da esquerda. Em 8 3 -, é 5, não −5.
  11. Fila cheia: com count, count == capacidade; sem count, (rear+1)%cap == front.
  12. pop() tem dois significados: na lista sequencial, o guia usa remove(0) (o repo deixa o método em branco); na pilha, remove o topo. Leia o contexto.
  13. Nomes das variantes do Bubble: no repo, sortO() é escopo reduzido e sortO2() é a mistura com mínimo. sortOptimized() não existe.
  14. SelectionSort.sortO1() não ordena: compara array[y] > array[x] em vez de array[x] < array[minIndx]. Em [9,1,4] termina em [4,1,9].
  15. Lista encadeada do professor enche: tem capacity e isFull(); add retorna false quando cheia.
  16. sortO2()/MinMaxSort com vetor vazio: estouram em swap(0,0). É o comportamento do código do repo.

07 Esqueletos para escrever na prova

Insert sequencial

insert
if (isFull() || pos < 0 || pos > count) return false;
for (int i = count; i > pos; i--)
    elements[i] = elements[i - 1];
elements[pos] = value;
count++;
return true;

Remove sequencial

remove
if (pos < 0 || pos >= count)
    throw new OperationFailed();
int removed = elements[pos];
for (int i = pos; i < count - 1; i++)
    elements[i] = elements[i + 1];
count--;
return removed;
